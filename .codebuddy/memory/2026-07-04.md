## Yii2 升级到 2.0.55

- 将 `yiisoft/yii2` 从 2.0.27 升级到 2.0.55，兼容 PHP 8.5
- 同步升级的依赖包：
  - `yiisoft/yii2-composer`: 2.0.7 → 2.0.11
  - `cebe/markdown`: 1.1.2 → 1.2.1
  - `ezyang/htmlpurifier`: v4.10.0 → v4.19.0
- `composer.json` 变更：
  - `php`: `>=5.6.0` → `>=7.4.0`
  - `yiisoft/yii2`: `~2.0` → `~2.0.55`
  - 新增 `asset-packagist.org` 仓库
- 创建了 `vendor/bower-asset -> bower` 和 `vendor/npm-asset -> npm` 软链接，兼容新旧 bower 资源路径
- Composer 全局配置：
  - 移除了过期的 GitHub OAuth token
  - Packagist 源从已失效的 `packagist.phpcomposer.com` 切换到 `mirrors.cloud.tencent.com/composer/`
  - 禁用了不兼容的 fxp/composer-asset-plugin 和旧版 yiisoft/yii2-composer 插件
- `composer.lock` 已更新匹配新版本
- **注意**：`yiisoft/yii2-swiftmailer` 依赖已废弃的 SwiftMailer，PHP 8.x 下可能需要替换为 `yiisoft/yii2-symfonymailer`

## 项目运行

- 服务器：`php -S 0.0.0.0:8888 -t web/ router.php`
- 路由脚本：`router.php`（处理 PHP 内置服务器的 URL 重写）
- 数据库：MySQL localhost:3306，库名 yiicms，用户 root/123456
- URL 后缀：`.html`（如 `/news/list.html`、`/products/list.html`）
- 后台入口：`/backend/default/login.html`
- 安装 bower-asset/bootstrap 3.4.1 到 `vendor/bower/bootstrap/dist/`（通过 npm）
